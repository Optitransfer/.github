<h3 align="center">Optitransfer</h3>

<p align="center">
Verifiable infrastructure for AI agents and distributed systems.<br>
Makers of crdt-merge, E4, acfa-rs and ATSP, plus open tools like x402-conformance.<br>
Proofs over promises.
</p>

---

| Project | What it does |
|---|---|
| [crdt-merge](https://github.com/mgillr/crdt-merge) | Conflict-free merge for DataFrames, JSON, ML models and distributed agents. Every merge is guaranteed to converge. |
| [acfa-rs](https://github.com/mgillr/acfa-rs) | Trains one model across parties that don't trust each other. A dishonest minority can't skew the result, and each round ships a receipt anyone can re-check offline. |
| [ATSP](https://github.com/mgillr/atsp-world) | Agent Trust and Sovereignty Protocol. ATSP World is a live experimental run that studies how autonomous agents behave and where their limits are. |
| [Proofline](https://github.com/Optitransfer/proofline) | Independent verification for coding agents. The agent says done; Proofline re-runs every check against a contract and gates the push. |
| [Truedone](https://github.com/Truedone/truedone) | Checks whether a pull request's tests prove its change: red without it, green with it. |
| [x402-conformance](https://github.com/atsp-protocol/x402-conformance) | Conformance and safety checks for x402 V2 facilitators and resource servers on Solana. |
